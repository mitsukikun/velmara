An original open-world crime game built for the make.fun **gta6-01** competition
("Make GTA 6"). Explore Velmara, a sun-soaked coastal city, on foot and by car
— steal cars, build a wanted level and outrun the Velmara PD, fight the Viper
gang, and run six story missions for Lena Cruz, from "Homecoming" to "The Big
Score". Nothing in it comes from Rockstar Games or any other commercial game:
the city, characters, vehicles, story, art and sounds are all original.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

**The city:** Velmara, a sun-soaked coastal city — a 7×7 grid of blocks with
avenues, a plaza, a park, a beach and docks, traffic and pedestrians.

**The game:** explore on foot and by car, steal cars, build a wanted level and
outrun the Velmara PD, fight the Viper gang, and run six story missions for
Lena Cruz — from "Homecoming" to "The Big Score". HUD with health, cash,
wanted stars, mission objectives and a live minimap. Keyboard + mouse,
synthesised sound and music, autosave + continue.

## Play

```sh
node serve.ts
# open http://localhost:8080
```

## Hand in

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
